# Input data and licenses

The representative case depends on two input files:

| Input | Required record | Redistribution status |
|---|---|---|
| JMA daily v2 CSV | source SHA-256 is recorded in the manifest | **To be confirmed before public release** |
| GPM 30-minute complete CSV | source SHA-256 is recorded in the manifest | **To be confirmed before public release** |

The current local reproduction record proves hash identity for the staged files. It does not by itself prove redistribution permission. Before a public GitHub release or Zenodo archive, record the authoritative source, version/date, license text or URL, attribution requirement, and whether redistribution is allowed.

If redistribution is not allowed, publish a fetch-and-verify instruction or a small legally redistributable fixture instead. Never upload restricted source data merely to make the public workflow convenient.
